## ✨ Features

- **Pixel-Accurate UI:** Matched layout, typography, exact color tokens, and paddings from the reference site.
- **Fully Responsive Design:** Optimized mobile menu drawer, multi-column grid adaptations, and fluid viewport scaling across mobile, tablet, and desktop screens.
- **Interactive Components:**
  - Responsive navigation bar with mobile toggle menu.
  - Interactive hero section with action states.
  - Popular links list with live clipboard copy state (`Copied!` tooltip) and QR trigger modal.
  - Seamless testimonial carousel supporting left/right navigation controls and auto-play transitions (1 card on mobile, 3 cards on desktop).
  - Feature highlights & visual analytics breakdown.
  - Transparent pricing tier layout.
  - Detailed multi-column footer with social links and contact info.

- **Styling:** Tailwind CSS
